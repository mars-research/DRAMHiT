## Hardware prefetchers: ON

    MSR 0x1a4 = 0x0 on all 128 cpus
      -> L2 streamer, L2 adjacent-line, DCU and DCU-IP all ENABLED

Set by `run_sweep_hwpref_on.sh`, NOT by `--hw-pref`. That flag is inert in this
tree (Application.cpp:794 is behind HARDCODE_PREFETCH_H14A, defined nowhere),
so a run's own log cannot testify to the prefetcher state it saw. The wrapper
therefore sampled 0x1a4 across all 128 cpus every 120 s for the whole sweep:

    logs/hwpref_on_msr_samples_20260920-142953.log
    118 samples, 14:29:53 -> 18:23:59, every one reading "128 cpus = 0x0"

The sweep's first run started 14:31:03 and its last finished 18:25:00, so the
samples cover the entire measured window (the sampler is killed by the wrapper's
trap ~1 min before the final run lands). No sample shows a mixed or flipped
state, so no stretch of runs needs discarding.

Restored to 0xf (prefetchers off) on exit and verified: "128 f".
